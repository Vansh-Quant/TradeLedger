# TradeLedger Workstation

Thin browser client for the existing TradeLedger application/API boundary.

## Scope

- Authenticated API connection
- Trading context
- Account order list
- Position/exposure display
- Order submission
- Order cancellation
- Idempotent mutation requests
- Connection, loading, and error states

Charts, WebSockets, market streaming, strategy tooling, AI/JARVIS, and client-side risk logic are intentionally deferred.
